# Просмотр всей валидации и загрузка своих серий

Я заменил целевую подборку ошибок полным набором RSNA VAL: **297 пациентов, 594 уровня L4–L5 и L5–S1**. Ответы — среднее вероятностей трёх заранее зафиксированных frozen-head v1, seed 42/2024/3407. При экспорте проверяю, что они совпадают с исходными CSV этих запусков, а метки и статусы — с кешем признаков. Нового обучения и подбора по TEST здесь нет.

Получилось 523 совпадения с метками RSNA, 65 расхождений и 6 отказов. Это сравнение с исходной разметкой, ещё не врачебная проверка. В фильтрах можно оставить любой из трёх типов. Сохранил номера прежних 146 случаев; новые добавил после них.

В карточке любого случая показываю сразу **оба уровня этого пациента**: L4–L5 и L5–S1. У каждого — собственный прогноз, метка RSNA, вероятности и результат сравнения. Пару нахожу по пациенту и уровню; соседние строки списка могут относиться к другим пациентам. Если запись отсутствует, неоднозначна или уровень не обработан, сохраняю «Не оценено». Эти две оценки остаются видимыми при переключении срезов и серий: они относятся к исследованию, а не являются новыми прогнозами для каждой открытой картинки. Переключатель уровня отдельно меняет область модели и ссылки на её исходные срезы. Прежние 594 ссылки на отдельные уровни продолжают открываться.

В пакете 773 доступные серии и 19 105 исходных DICOM. Для всех пациентов доступны сагиттальные и аксиальные T2; 169 дополнительных T1-серий пока не скачаны и отмечены отсутствующими. ZIP содержит исходные байты DICOM, превью нужны для просмотра в браузере. В обзоре каждого обработанного уровня показываю все 9 слоёв ROI с точными ссылками на исходные срезы. Если слой дополнен нулями на границе серии, отмечаю это отдельно.

## Что можно загрузить

В разделе «Загрузки» принимаю **ZIP одной полной обезличенной сагиттальной T2 MR-серии**, в том числе с вложенной папкой. Это должны быть обычные однофреймовые DICOM с геометрией, а не JPEG, PDF или скриншот. Подтип T2 автоматически не подтверждается: за выбор серии отвечает загружающий. Несколько серий или пациентов в одном архиве не смешиваю, аксиальную серию сагиттальной модели не подаю.

После передачи сервер сохраняет задание, проверяет DICOM и запускает в отдельном процессе прежний `run_inference` с тремя головами. Очередь обрабатывает одно исследование за раз. Для каждого уровня выдаются категория, некалиброванные оценки трёх классов или явная причина отказа. Результат можно скачать в JSON; серия и ответ остаются в списке загрузок.

Текущий вход классификатора остаётся прежним: **9 соседних слоёв ROI на уровень**, а не вся глубина серии. Полная серия участвует в локализации. Опубликованные метрики RSNA не служат оценкой точности на произвольных загруженных исследованиях.

Загрузка доступна по той же закрытой ссылке, что и просмотрщик. Это общий список для всех, у кого есть эта ссылка; отдельных аккаунтов нет. Сервер не публикует в JSON имена, DICOM UID или исходные названия файлов. Однако оригиналы DICOM сохраняют исходные заголовки и доступны для скачивания по закрытой ссылке, поэтому загружать нужно уже обезличенные исследования. Автоматическое удаление надписей, записанных в пиксели, не реализовано.

Ограничения: ZIP и суммарный распакованный объём — по 256 МиБ, не больше 512 файлов, изображения до 2048×2048 и не больше 32 млн пикселей на серию. На хранилище загрузок выделено 1 ГиБ и не больше 100 исследований; для активных заданий резервируется место. Таймаут одного анализа — 15 минут. При нехватке места, неверном формате или прерывании результат не подменяется нормой.

## Пересобрать подборку

```bash
python -m ai_spine_med.review_export --output reports/runs/physician-review-all-v13
cp src/ai_spine_med/review_web/* reports/runs/physician-review-all-v13/site/
```

Экспорт переиспользует проверенные старые файлы и может продолжаться после прерывания. Медицинские изображения и приватные индексы остаются в игнорируемом каталоге `reports/runs/`.

## Запустить сервер

```bash
export REVIEW_ROOT=/absolute/path/to/physician-review-all-v13
export REVIEW_UPLOAD_ROOT=/absolute/path/to/private-uploads
export REVIEW_MODEL_CACHE=/absolute/path/to/.cache
export REVIEW_INFERENCE_HEADS='["/absolute/path/to/head-v1/runs/seed-42/head.pt","/absolute/path/to/head-v1/runs/seed-2024/head.pt","/absolute/path/to/head-v1/runs/seed-3407/head.pt"]'
export REVIEW_ORIGIN=https://your-review-host.example
# REVIEW_TOKEN — отдельный случайный секрет, минимум 24 URL-safe символа.
ai-spine-review --port 8768
```

Рядом с головами нужны исходные `manifest.json` и `summary.json`. В кеше — проверенные исходники SpineNet, архив исходников и оригинальные веса. Модель и препроцессинг проходят ту же проверку происхождения, что и отдельная CLI-команда `ai-spine predict`.

Шаблоны изолированного CPU-контейнера лежат в `deploy/review/`. Внутри контейнера сервер слушает `0.0.0.0`, но Docker публикует порт **только на 127.0.0.1**. Медицинские данные и модели монтируются отдельно, загрузки — единственный постоянный каталог с правом записи. Нужен HTTPS reverse proxy; в рабочем развёртывании прежний HTTPS-адрес на back связан с сервисом на mine-test через SSH-туннель. Закрытый URL и ключи в репозиторий не входят.

Для reverse proxy нужны `client_max_body_size 256m`, отключённое буферизование тела запроса и достаточный таймаут передачи. На сервере не ведётся журнал URL, содержащих секрет ссылки. POST загрузки требует правильный Origin, тот же секрет маршрута и специальный заголовок намерения загрузки. Пользовательские веса и исполняемые файлы не принимаются.

## Что проверил перед публикацией

Проверил всю цепочку: выбор ZIP в браузере → передача через HTTPS → анализ на mine-test → сохранение ответа → просмотр исходных срезов и скачивание JSON. На тестовой серии из 18 срезов оба уровня обработались; вероятности совпали с сохранённым v1 ансамблем с допуском `1e-4`. Первый запуск на CPU занял около 205 секунд. После обновления страницы и перезапуска контейнера серия и результат сохранились. В разделе оставил одну тестовую загрузку RSNA.

На сервере сверил контрольные суммы всех **19 105 исходных DICOM**, **19 105 превью**, ZIP и обзорных областей модели — расхождений нет. Через HTTPS дополнительно проверил последние добавленные серии, выдачу исходных файлов и запреты доступа без секрета или с посторонним Origin.

Общий набор Python-тестов прошёл: **769 тестов**. Для интерфейса отдельно прошли **13 поведенческих проверок**: переключение между разделами при медленном ответе, сброс снимков предыдущего пациента, открытие центрального слоя ROI, правильное сопоставление двух уровней одного пациента, независимые метки RSNA, отказы второго уровня и сохранение обеих оценок при смене среза или области модели. Это техническая проверка сайта и воспроизводимости модели; врачебной оценки она не заменяет.
