## Запуск SpineNet

Фактически скачаны исходники SpineNet `5e96ac54b1c1845a37d12e40bfd16f647d40acd8`, все четыре файла весов и оба официальных примера поясничной T2. SHA-256 зафиксированы в `src/ai_spine_med/assets.lock.json`. Суммарный размер весов — 821 857 187 байт.

Окружение: macOS ARM64, Python 3.12.14, torch 2.14.1, torchvision 0.29.1, NumPy 1.26.4, pydicom 3.0.2. CPU, четыре потока. Полный список пакетов — `requirements-macos-arm64-py312.lock`.

Команда успешной проверки:

```bash
python -m ai_spine_med smoke --examples-root data/examples --out reports/runs/official-examples-cpu-fixed --device cpu
```

Загрузка моделей заняла 0,99 с; скачивание и первоначальная инициализация библиотек в эти времена не входят. Получены оценки всех четырёх целевых областей и файлы CSV/JSON. Извлечённые области имеют форму `(9, 112, 224)`.

Это два демонстрационных набора изображений, а не независимая клиническая выборка. У них отсутствует часть геометрии DICOM; для запуска использована подстановка метаданных из официального quickstart. Эталонной разметки нет, точность не вычислялась. Файлы имеют одинаковый SeriesUID, поэтому использовать их для оценки независимости пациентов нельзя.

Исправления для воспроизводимости запуска:

- в локальной копии исходников `np.bool` заменён на `bool`; архитектура и веса не изменены;
- NumPy закреплён `<2` из-за `ndarray.ptp()` в исходниках;
- метаданные `numpy.float64` в checkpoint разрешены узким scoped allowlist PyTorch; `weights_only=False` не включался;
- в рабочем загрузчике реальные серии сортируются по геометрии, а не имени файла или `InstanceNumber`.
