Окружение: macOS ARM64, Python 3.12.14, torch 2.14.1, torchvision 0.29.1, NumPy 1.26.4, pydicom 3.0.2. CPU, четыре потока. Полный список пакетов — `requirements-macos-arm64-py312.lock`.

Загрузка моделей заняла 0,99 с; скачивание и первоначальная инициализация библиотек в эти времена не входят. Получены оценки всех четырёх целевых областей и файлы CSV/JSON. Извлечённые области имеют форму `(9, 112, 224)`.

Это два демонстрационных набора изображений, а не независимая клиническая выборка. У них отсутствует часть геометрии DICOM; для запуска использована подстановка метаданных из официального quickstart. Эталонной разметки нет, точность не вычислялась. Файлы имеют одинаковый SeriesUID, поэтому использовать их для оценки независимости пациентов нельзя.

Исправления для воспроизводимости запуска:

- в локальной копии исходников `np.bool` заменён на `bool`; архитектура и веса не изменены;
- NumPy закреплён `<2` из-за `ndarray.ptp()` в исходниках;
- метаданные `numpy.float64` в checkpoint разрешены узким scoped allowlist PyTorch; `weights_only=False` не включался;
- в рабочем загрузчике реальные серии сортируются по геометрии, а не имени файла или `InstanceNumber`.

## Данные RSNA

Три официальные таблицы RSNA успешно скачаны через Kaggle API. Подготовка выполнена на реальных данных с `seed=42`. Из 1 975 исходных исследований одно не имеет серии `Sagittal T2/STIR` и исключено. Получено **1 974 исследования / серии и 3 948 меток двух уровней**.

| Выборка | Исследований | Норма / лёгкий | Умеренный | Тяжёлый |
| --- | ---: | ---: | ---: | ---: |
| Train | 1 382 | 2 369 | 203 | 192 |
| Validation | 297 | 509 | 43 | 42 |
| Test | 295 | 508 | 42 | 40 |

Числа классов считаются по уровням, а не по пациентам: у исследования две метки. Проверяется отсутствие пересечений `study_id`; все серии и уровни группы остаются вместе. Фиксированные таблицы находятся локально в `artifacts/rsna-v1/`, исходные — в `data/rsna/`. Они исключены из Git в соответствии с условиями данных. SHA-256 `studies.csv`: `1fc2705dc36ce97179fb1b38e08a5c7c1e3e8f8852d5cb1d82874e9f19d46004`.

Дисбаланс существенен: тяжёлый стеноз L5–S1 встречается только в **19 исследованиях** (13 / 3 / 3 в train / validation / test). Оценки чувствительности отдельно для этого уровня будут иметь большую неопределённость. На L4–L5 тяжёлых случаев 255. Исходные пропуски меток не перекодировались в норму.

Подготовка относится к категории `Sagittal T2/STIR`, а не к отдельно подтверждённой обычной T2. Подтип последовательности ещё ожидает контроля. Скачаны три полные серии из train, по одной из каждой группы худшей степени стеноза: **54 DICOM-файла, около 11 MB**. Полные наборы изображений всех 1 974 исследований ещё не скачаны. Выборочное скачивание проверено повторно: 0 новых файлов, 54 уже присутствующих. Список файлов каждой серии получен через официальный SDK API каталогов; проверено совпадение числа файлов с `total_files`.

## Запуск на реальных сериях RSNA

Все три серии прочитаны строгим загрузчиком без подстановки демонстрационных метаданных и обработаны исходной моделью на CPU, четыре потока.

| Обучающий пример | Размер входа H×W×S | Оценено целевых уровней | Время после загрузки модели |
| --- | --- | ---: | ---: |
| 1 | 448×448×18 | 1 из 2 | 9,14 с |
| 2 | 448×448×18 | 2 из 2 | 9,26 с |
| 3 | 462×448×18 | 2 из 2 | 10,64 с |

В первом примере исходный SpineNet не выдал область с именем L5–S1. Этот уровень сохранён как `not_assessed`; он не приравнивается к норме. Итоговое покрытие — **5 из 6 целевых областей**, полностью оценены две из трёх серий. Корректность нумерации и соответствие областей анатомии ещё требует визуального контроля; это следующий этап плана.

Это проверка работоспособности на трёх выбранных **обучающих** исследованиях. Она не является валидацией, не измеряет точность и не позволяет оценить частоту отказов на всей популяции. Предсказания на validation/test не запускались. Локальные результаты находятся в `reports/runs/rsna-train-1/`, `rsna-train-2/`, `rsna-train-3/` и не публикуются вместе с данными.

Проверены на искусственных данных: группировка исследований, учёт пропусков и классов, воспроизводимость при перестановке строк, сохранность установленного разбиения, изоляция train при выборочном скачивании, пагинация и неполный каталог. Реальный отказ без авторизации Kaggle завершается понятным сообщением, не открывает браузер и не печатает токены.
