# Можно ли находить уровни только по аксиальным МРТ и XML

В XML-ветке 350 пациентов TRAIN и 695 анатомических ориентиров двух нужных уровней.

Я отдельно обучил модель выбора уровня только по XML AISSLab. Сагиттальные снимки для него не нужны. В предыдущем v6 центр канала уже обучался только по этим XML; здесь я оставил его веса без изменений и сравнил именно выбор среза.

На AISSLab оба варианта уверенно находят размеченные уровни. При переносе на RSNA вариант только с XML заметно уступает смешанному; разница сохраняется в парных интервалах ниже. Поэтому для изображений другого источника я пока оставляю смешанное обучение, а XML использую как полезную анатомическую разметку.

Второй вариант использует и AISSLab, и приблизительные ориентиры уровней RSNA. Для каждого варианта сделал три запуска с seed 42, 2024 и 3407. Архитектура, лимит эпох и критерий выбора эпохи одинаковые: среднее попадание в пределах 10 мм по двум уровням AISSLab VAL, при равенстве — меньшая cross-entropy. Вариант без дообучения, использующий только позиционный prior, тоже мог быть выбран.

Все шесть моделей зафиксированы до оценки RSNA VAL. Центр, классификатор степени стеноза и TEST на этом шаге не обучал и не переоценивал.

## Что сравнивается и где ограничения

Это сравнение двух схем обучения по источнику разметки. Одновременно меняются количество пациентов, домен изображений, нормализаторы и позиционный prior, поэтому разницу нельзя приписать только качеству XML. Prior рассчитывается отдельно по TRAIN каждого варианта; в JSON сохранены результаты его проверки. Смешанная ветка также получает больше обновлений оптимизатора за эпоху, поскольку её TRAIN больше. Число обновлений между ветками не выравнивал.

AISSLab VAL используется для выбора эпохи, поэтому его оценки оптимистичны. RSNA VAL в этом эксперименте используется только после фиксации весов, но эта выборка уже применялась в прошлой работе: это не новый независимый тест. Прежний смешанный v6 выбирал эпоху по другому критерию — по обоим датасетам; его прежние числа нельзя трактовать как третью равноправную ветку этого сравнения.

У AISSLab ориентир — размеченный XML срез и центр bounding box канала. Это слабый анатомический ориентир, а не маска сегментации канала. Клиническую правильность предсказанного центра ещё нужно проверить с врачом. У RSNA координаты субартикулярных областей дают приблизительный уровень, а не точную разметку центра канала. Попадание в 10 мм не означает правильную оценку стеноза. На этом шаге я не проверял улучшение классификации степени, контура или площади канала.
